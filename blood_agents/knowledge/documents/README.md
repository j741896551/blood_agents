# 献血知识库说明

本目录保存有出处的献血公开资料人工摘要，不是公司内部知识库镜像。

- `industry/`：基于国家卫健委、国家标准平台及省级卫健部门公开材料的人工摘要，覆盖献血法、2026 版规程间隔、献血前筛查与知情同意、全血/单采血小板区别、献血前后注意、血液检测及去向的一般流程、电子献血证、血费减免和国家表彰。原文 URL、发布日期与核对日期在上级 `corpus.json`；内容并非实时同步，2026 版规程已替代 2019 版，不能继续用旧版间隔计算。健康信息不能替代医护人员判断。

业务规则、个人账户和订单资料不在默认知识库内；它们只能来自对应业务接口的当轮回执。

运行时按 `corpus.json` 白名单读取 Markdown，切分后检索；用户提问不会触发网页抓取。新增资料时先审查来源、版权与敏感信息，并更新清单、正反例测试和日期。预约名额、积分余额、订单与个人献血记录只能从本轮业务工具回执获取，不能从这里回答。

知识库保存的是短篇人工改写摘要，不镜像官方 PDF/网页全文。资料增多只表示主题变广，不能直接宣称“覆盖大部分问法”：须分别评测每类问题的召回、证据核验、来源一致性和最终答复，并保留个人资格、实时政策、地方减免额度等无依据负例。
