## 重建

在已安装 Pillow 的 Python 环境中执行。默认从提交的 `sources.json` 重建，因此仅检出文档版本也可生成图册。

```bash
.venv312/bin/python docs/diagrams/build_diagrams.py
```

在完整集成工作区，用 `--from-source` 重新核对源码锚点及工具列表。生成预览需要中文字体。macOS 默认使用系统 STHeiti，其他系统可通过 `BLOOD_DIAGRAM_FONT` 指定字体路径，或安装脚本支持的 Noto CJK 字体。生成器会覆盖同名派生文件，布局调整应在图源声明中维护。

来源及阅读入口：[图册索引](README.md)、[时序图](SEQUENCES.md)、[sources.json](sources.json)。
